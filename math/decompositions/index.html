Eigenvectors and decompositions

A decomposition rewrites one awkward matrix as a product of simple ones: diagonal, triangular or orthogonal. Each simple piece is easy to understand and cheap to compute with, so a hard problem becomes a few easy ones. This page builds the four you will meet most: eigen, LU, QR and Cholesky.

What is a decomposition, in plain words?

The idea

We factor numbers to understand them: \(84=2^2\cdot3\cdot7\) tells you at a glance what divides 84. Matrices can be factored too, and the factors play the same role. A diagonal matrix just stretches each axis. A triangular matrix can be solved one row at a time. An orthogonal matrix is a pure rotation or reflection that keeps lengths. Write \(A\) as a product of such pieces and every question about \(A\) becomes a question about the pieces.

Which factorisation to use depends on the question. "What does \(A\) do when applied many times?" calls for eigenvectors. "Solve \(Ax=b\) for many \(b\)" calls for LU. "Least squares, stably" calls for QR. "Sample from a Gaussian" calls for Cholesky.

How it works

  1. Find the special directions or the elimination steps hidden in \(A\).
  2. Record them as factors: \(A=V\Lambda V^{-1}\), \(A=LU\), \(A=QR\) or \(A=LL^\top\).
  3. Solve, invert, take powers or sample using the easy factors.
  4. Pay the factoring cost once and reuse it many times.

An everyday picture

Kneading dough. Each push stretches the dough more in some directions than others. Most lines you draw on it get both turned and stretched, but a few special lines only get longer or shorter, staying on the same line. Those are the eigen-directions, and the stretch along each is its eigenvalue.

Good at
  • Turning \(O(n^3)\) work into reusable \(O(n^2)\) solves
  • Revealing structure: stretch directions, rank, stability
  • Numerical accuracy when chosen well
Watch out for
  • Not every matrix has real eigenvectors (rotations)
  • Some factorisations need special matrices (Cholesky needs SPD)

1Eigenvectors: directions that only stretch

Drag \(x\) around the unit circle. The orange arrow is \(Ax\). The dashed lines are the eigen-directions: put \(x\) on one and \(Ax\) lines up with it.

Apply a matrix to vectors pointing in every direction (the unit circle) and the circle becomes an ellipse. Almost every vector is both stretched and turned. We are looking for the exceptions: nonzero vectors \(v\) that come out pointing along the same line,

$$Av=\lambda v .$$

\(v\) is an eigenvector and the number \(\lambda\) is its eigenvalue: the stretch factor (negative means it flips). How do we find them?

  1. \(Av-\lambda v=0\;\Rightarrow\;(A-\lambda I)v=0\)
    Move everything to one side; \(\lambda v=\lambda Iv\).
  2. \(\det(A-\lambda I)=0\)
    A nonzero \(v\) is sent to 0 only if \(A-\lambda I\) flattens space (see determinants).
  3. \(\lambda^2-(\operatorname{tr}A)\lambda+\det A=0\)
    For a \(2\times2\) matrix, expand \((a-\lambda)(d-\lambda)-bc\). The trace is \(a+d\).

Solve the quadratic for \(\lambda\), then solve \((A-\lambda I)v=0\) for the direction. A rotation has no real solutions, because it turns every direction; its eigenvalues are complex.

Going deeper: complex eigenvalues, multiplicity, and why symmetric matrices are special

Over the complex numbers every \(n\times n\) matrix has exactly \(n\) eigenvalues counted with multiplicity, because \(\det(A-\lambda I)\) is a degree-\(n\) polynomial. A rotation by \(\phi\) has \(\lambda=e^{\pm i\phi}\): the modulus 1 says "no stretching" and the angle says "turn by \(\phi\)".

A repeated eigenvalue may not come with enough eigenvectors. The shear \(\begin{bmatrix}1&1\\0&1\end{bmatrix}\) has \(\lambda=1\) twice but only one eigen-direction, so it cannot be diagonalised. Such matrices are called defective; the Jordan form handles them.

Spectral theorem. A real symmetric matrix has real eigenvalues and an orthonormal basis of eigenvectors, so \(A=Q\Lambda Q^\top\). Proof sketch for two distinct eigenvalues: \(\lambda_1v_1^\top v_2=(Av_1)^\top v_2=v_1^\top Av_2=\lambda_2v_1^\top v_2\), so \((\lambda_1-\lambda_2)v_1^\top v_2=0\) and \(v_1\perp v_2\). Covariance matrices, Hessians and kernel matrices are all symmetric. That is why PCA always finds perpendicular axes.

The Rayleigh quotient \(R(x)=\frac{x^\top Ax}{x^\top x}\) of a symmetric matrix is largest at the top eigenvector, where it equals \(\lambda_{\max}\). This is exactly the "maximise variance" statement of PCA.

2Eigendecomposition and powers of a matrix

Apply \(A\) again and again to the starting vector (drag it). After normalising each step, the arrow swings onto the eigenvector with the largest \(|\lambda|\).

Suppose a \(2\times2\) matrix has two independent eigenvectors \(v_1,v_2\). Use them as a new set of axes. In those axes, \(A\) does nothing but stretch axis 1 by \(\lambda_1\) and axis 2 by \(\lambda_2\). Put the eigenvectors in the columns of \(V\) and the eigenvalues on the diagonal of \(\Lambda\):

$$A=V\Lambda V^{-1}$$

Read it right to left: change to eigen-axes (\(V^{-1}\)), stretch each axis (\(\Lambda\)), change back (\(V\)).

The payoff is powers: \(A^k=V\Lambda V^{-1}V\Lambda V^{-1}\cdots=V\Lambda^kV^{-1}\), and \(\Lambda^k\) just raises each \(\lambda_i\) to the \(k\)-th power. Write the start vector as \(x_0=c_1v_1+c_2v_2\). Then

$$A^kx_0=c_1\lambda_1^k\,v_1+c_2\lambda_2^k\,v_2 .$$

If \(|\lambda_1|>|\lambda_2|\), the first term wins exponentially fast, at a rate \(|\lambda_2/\lambda_1|^k\). That is power iteration, the idea behind PageRank and behind exploding and vanishing gradients in RNNs, where the same weight matrix is applied at every time step.

Algorithm: power iteration
  1. input square matrix \(A\), start vector \(x_0 \ne 0\), tolerance \(\varepsilon\)
  2. \(x \leftarrow x_0 / \|x_0\|\)
  3. repeat
  4. \(y \leftarrow Ax\) one matrix–vector product: cheap even for huge sparse A
  5. \(\lambda \leftarrow x^\top y\) Rayleigh quotient: current eigenvalue estimate
  6. \(x \leftarrow y / \|y\|\) normalise so the numbers stay finite
  7. until \(x\) changes by less than \(\varepsilon\)
  8. return \(\lambda, x\) dominant eigenpair; error shrinks like |λ₂/λ₁|ᵏ

Uses the matrix from section 1. Try a matrix whose eigenvalues are close in size and watch convergence slow down.

3LU: elimination, written down

On the matrices page we solved systems by row reduction. Each step "subtract \(\ell\) times row \(j\) from row \(i\)" is a small matrix. Collect all those multipliers \(\ell_{ij}\) in a lower-triangular matrix \(L\) (ones on the diagonal), and the end result of elimination in an upper-triangular \(U\):

$$PA=LU .$$

\(P\) records any row swaps (pivoting, for numerical safety). Why bother? Because triangular systems are trivial to solve. To solve \(Ax=b\): first solve \(Ly=Pb\) from the top down (forward substitution), then \(Ux=y\) from the bottom up (back substitution). Factoring costs about \(\tfrac23n^3\) operations once; each new \(b\) then costs only \(2n^2\).

Edit \(A\) and \(b\): the factors and both substitutions update.

Algorithm: LU with partial pivoting, then solve
  1. \(U \leftarrow A\); \(L \leftarrow I\); \(P \leftarrow I\)
  2. for \(c = 1\) to \(n-1\) do
  3. swap row \(c\) of \(U\) with the row below having the largest \(|U_{rc}|\); record it in \(P\) (and \(L\)'s finished columns)
  4. for \(r = c+1\) to \(n\) do
  5. \(L_{rc} \leftarrow U_{rc}/U_{cc}\); row\(_r(U) \leftarrow\) row\(_r(U) - L_{rc}\,\)row\(_c(U)\)
  6. solve Ax = b using the factors
  7. for \(i = 1\) to \(n\): \(y_i \leftarrow (Pb)_i - \sum_{k<i} L_{ik}y_k\) forward
  8. for \(i = n\) down to 1: \(x_i \leftarrow (y_i - \sum_{k>i} U_{ik}x_k)/U_{ii}\) backward
  9. return \(x\)

4QR: Gram–Schmidt, written down

Drag \(a_1\) and \(a_2\). Gram–Schmidt turns them into perpendicular unit vectors \(q_1, q_2\) spanning the same plane.

The projections page showed that orthonormal bases make projection easy. Gram–Schmidt makes one from any independent columns:

  1. \(q_1=a_1/\|a_1\|\)
    Keep the first direction, scaled to length 1.
  2. \(u_2=a_2-(q_1\cdot a_2)\,q_1\)
    Remove the part of \(a_2\) that lies along \(q_1\) (its projection). What remains is perpendicular to \(q_1\).
  3. \(q_2=u_2/\|u_2\|\)
    Scale to length 1. With more columns, subtract the projections onto all previous \(q\)'s.

Reading the steps backwards gives \(a_1=r_{11}q_1\) and \(a_2=r_{12}q_1+r_{22}q_2\). In matrix form:

$$A=QR,\qquad Q^\top Q=I,\ R\text{ upper triangular}.$$

For least squares, substitute into the normal equations: \(R^\top Q^\top QR\theta=R^\top Q^\top y\) simplifies to \(R\theta=Q^\top y\), a triangular solve, without ever forming \(X^\top X\). This is what np.linalg.lstsq and most regression libraries do.

Algorithm: Gram–Schmidt QR
  1. input columns \(a_1,\dots,a_n\) of \(A\)
  2. for \(j = 1\) to \(n\) do
  3. \(u \leftarrow a_j\)
  4. for \(i = 1\) to \(j-1\) do
  5. \(R_{ij} \leftarrow q_i \cdot u\); \(u \leftarrow u - R_{ij}\,q_i\) modified G–S: project the running u, more stable
  6. \(R_{jj} \leftarrow \|u\|\); \(q_j \leftarrow u/R_{jj}\) R_jj ≈ 0 means a_j depends on earlier columns
  7. return \(Q = [q_1 \cdots q_n]\), \(R\)

5Cholesky: a square root for covariance matrices

Each dot is \(\mu+Lz\), where \(z\) is a pair of independent standard normal numbers. Change the covariance and the same \(z\)'s are reshaped.

A symmetric matrix with \(x^\top Ax>0\) for every \(x\ne0\) is positive definite. Covariance matrices are (at least semi-) definite, because \(x^\top\Sigma x\) is the variance of the combined feature \(x^\top z\) (a weighted sum of the variables), and a variance cannot be negative. Such matrices have a triangular "square root":

$$\Sigma=LL^\top,\qquad L\ \text{lower triangular with positive diagonal}.$$

It is LU made symmetric, at half the cost. A neat use: to draw samples with covariance \(\Sigma\), take independent standard normals \(z\) and set \(x=\mu+Lz\). Then \(\operatorname{Cov}(x)=L\operatorname{Cov}(z)L^\top=LIL^\top=\Sigma\). Gaussian processes, Kalman filters and the reparameterisation trick in VAEs all use this.

Algorithm: Cholesky factorisation
  1. input symmetric positive definite \(A\) (\(n\times n\))
  2. for \(i = 1\) to \(n\) do
  3. for \(j = 1\) to \(i\) do
  4. \(s \leftarrow A_{ij} - \sum_{k<j} L_{ik}L_{jk}\)
  5. if \(i = j\) then if \(s \le 0\) then fail not positive definite; \(L_{ii} \leftarrow \sqrt s\)
  6. else \(L_{ij} \leftarrow s / L_{jj}\)
  7. return \(L\) sample: x = μ + L z with z ~ N(0, I)
Going deeper: why Cholesky can fail, and what that tells you

The algorithm takes a square root of \(s=A_{ii}-\sum_kL_{ik}^2\) at every diagonal step. The theorem is that \(A\) is positive definite if and only if every such \(s\) is positive. So attempting a Cholesky factorisation is also the cheapest test of positive definiteness. Optimisers use it to check that a Newton step points downhill.

Positive definite has several equivalent faces: \(x^\top Ax>0\) for all \(x\ne0\); all eigenvalues positive; all leading principal minors positive; \(A=B^\top B\) for some \(B\) with independent columns. The last is why \(X^\top X\) (for independent features) and every covariance matrix with no exactly redundant variables qualify. In practice a covariance estimated from fewer samples than dimensions is only semi-definite, so libraries add a small "jitter" \(\epsilon I\) before factoring.

7The same thing in Python (NumPy / SciPy)

import numpy as np, scipy.linalg as sl
A = np.array([[2., 1.], [1., 3.]])
lam, V = np.linalg.eig(A)               # A @ V[:, i] == lam[i] * V[:, i]
lam, Q = np.linalg.eigh(A)              # symmetric: real, orthonormal (preferred)
np.allclose(Q @ np.diag(lam) @ Q.T, A)
P, L, U = sl.lu(A)                      # A = P @ L @ U
lu = sl.lu_factor(A); sl.lu_solve(lu, np.array([1., 2.]))   # reuse for many b
Q, R = np.linalg.qr(A)                  # Q.T @ Q == I, R upper triangular
L = np.linalg.cholesky(A)               # A = L @ L.T (fails if not positive definite)
x = np.array([0., 0.]) + L @ np.random.randn(2, 1000)   # samples with covariance A
