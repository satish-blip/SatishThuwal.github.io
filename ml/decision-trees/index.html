What is a decision tree, in plain words?

The idea

A decision tree is a flowchart of yes/no questions about the features: "Is \(x_1 < 0.3\)? If yes, is \(x_2 > 1.2\)?" Each answer sends a point down one branch until it reaches a leaf, which holds the prediction.

The tree is grown greedily: at every node it tries every possible question and keeps the split that makes the two groups as "pure" (single-class) as possible, measured by Gini impurity or entropy. Because every question is about one feature, the boundary is made of horizontal and vertical steps.

How it works

  1. Start with all training points in one node.
  2. Try every feature and every threshold; score each split by the drop in impurity.
  3. Keep the best split and repeat on each child.
  4. Stop at a maximum depth, a minimum leaf size or a pure node; optionally prune back.

An everyday picture

The game "20 questions", or a doctor’s triage chart: each question narrows the possibilities until the answer is obvious.

Good at
  • Easy to explain and draw
  • No feature scaling needed
  • Handles mixed and non-linear data
Watch out for
  • Deep trees overfit badly
  • Small changes in the data can change the whole tree
  • Staircase boundaries for diagonal patterns

2How a split is chosen:

split on \(x_1\)split on \(x_2\)★ best (chosen) threshold

Every possible threshold (midpoints between consecutive sorted values) for both features, scored by impurity decrease. CART is greedy: it takes the highest point, without looking ahead.

Why greedy fails on XOR. At the root of the XOR dataset no single cut improves purity much, because each half still holds both classes in equal parts. Select XOR and look at the root's scan: the curve is almost flat. The tree still gets there with depth, but the first split is close to arbitrary.

3The maths

Impurity of a node

With \(p\) the fraction of class 1 in a node:

$$\begin{aligned}\text{Gini}&=1-p^2-(1-p)^2=2p(1-p)\\ \text{Entropy}&=-p\log_2p-(1-p)\log_2(1-p)\\ \text{Error}&=\min(p,\,1-p)\end{aligned}$$
GiniEntropy (scaled by ½ to compare)Misclassification

Gini and entropy are strictly concave, so a split that makes children purer on average always reduces them. Misclassification error is piecewise linear: many useful splits leave it unchanged, which is why it is a poor criterion for growing trees.

Choosing a split

$$\Delta(j,t)=I(\text{parent})-\frac{n_L}{n}I(\text{left})-\frac{n_R}{n}I(\text{right}),\qquad (j^\star,t^\star)=\arg\max_{j,\,t}\Delta(j,t)$$

The search costs \(O(d\,n\log n)\) per node: sort each feature once and sweep the thresholds while updating class counts. With entropy, \(\Delta\) is the information gain.

The algorithm (CART)

  1. Start with all training points in the root.
  2. If the node is pure, at max depth, or too small, make it a leaf that predicts its majority class (or class fraction).
  3. Otherwise find \((j^\star,t^\star)\), send points with \(x_j\le t^\star\) left and the rest right, and recurse.

Controlling complexity

A fully grown tree reaches zero training error on any data without duplicate points, so it overfits. Limit depth or leaf size, or grow fully and then prune by cost-complexity:

$$R_\alpha(T)=\sum_{\text{leaves }m}n_m\,I_m+\alpha\,|T|$$

Trees are unstable (high variance): small data changes can change the top split and everything below it. That weakness is exactly what bagging and random forests fix on the next page.

4Depth and overfitting

training accuracytest accuracy (fresh 400 points)dashed: current max depth

Training accuracy climbs to 100% as the tree deepens. Test accuracy peaks and then falls, or flattens, as the extra leaves carve out noise. The gap between the two curves is variance.

Trees have real strengths: they need no feature scaling, handle mixed feature types, capture interactions automatically and are easy to read. Their boundaries are always axis-aligned staircases, so a diagonal line needs many splits; compare Linear blobs here with logistic regression.

5The same thing in Python

from sklearn.tree import DecisionTreeClassifier, plot_tree, export_text

tree = DecisionTreeClassifier(criterion="gini", max_depth=6, min_samples_leaf=1).fit(X, y)
print(export_text(tree, feature_names=["x1", "x2"]))
plot_tree(tree, filled=True)

# cost-complexity pruning path, then pick alpha by cross-validation
path = tree.cost_complexity_pruning_path(X, y)
pruned = DecisionTreeClassifier(ccp_alpha=path.ccp_alphas[-3]).fit(X, y)
