What is linear regression, in plain words?

The idea

Linear regression predicts a number from one or more inputs by drawing the straight line (or flat surface) that runs closest to the data. "Closest" means the squared vertical gaps between the points and the line, the residuals, add up to as little as possible: this is least squares.

Add powers of \(x\) as extra inputs (polynomial features) and the same method fits curves. Add a penalty on large coefficients and it becomes ridge or the lasso, which resist overfitting.

How it works

  1. Write the prediction as \(\hat y = w_0 + w_1x_1 + \dots + w_dx_d\).
  2. Measure the error with the mean squared error.
  3. Find the weights that make it smallest: in one shot with the normal equations, or step by step with gradient descent.
  4. Check the fit with R² and the residuals, and on new data.

An everyday picture

Predicting sales from TV advertising spend (the classic Advertising dataset): each extra $1000 of TV spend adds roughly the same number of sales, so a straight line through the scatter tells you the trend and the typical return.

Good at
  • Fast, exact solution
  • Easy to read: each weight is an effect size
  • A strong baseline for any number-prediction task
Watch out for

2The maths, with your numbers

Everything below is computed from the points currently on the plot, using a straight line (degree 1) exactly as in TA Tutorials 2 and 3.

Model and loss

$$y_i=\beta_0+\beta_1x_i+\varepsilon_i,\qquad \mathrm{RSS}(\beta)=\sum_{i=1}^n\big(y_i-\beta_0-\beta_1x_i\big)^2=\lVert y-X\beta\rVert^2$$

Stack a column of ones next to \(x\) to get the design matrix \(X\in\mathbb R^{n\times 2}\). Setting the gradient \(\nabla_\beta \mathrm{RSS}=-2X^\top(y-X\beta)\) to zero gives the normal equations:

$$X^\top X\,\hat\beta=X^\top y\quad\Longrightarrow\quad \hat\beta=(X^\top X)^{-1}X^\top y$$

This needs \(X\) to have full column rank. If one column is a multiple of another, \(X^\top X\) is singular and the solution is not unique.

Geometry: a projection

\(\hat y=X\hat\beta=Hy\) with the hat matrix \(H=X(X^\top X)^{-1}X^\top\). \(H\) projects \(y\) onto the column space of \(X\), so the residual is orthogonal to every column: \(X^\top e=0\). That is why residuals always sum to zero when there is an intercept.

How good is the fit?

$$\underbrace{\sum(y_i-\bar y)^2}_{\mathrm{TSS}}=\underbrace{\sum(\hat y_i-\bar y)^2}_{\mathrm{MSS}}+\underbrace{\sum(y_i-\hat y_i)^2}_{\mathrm{RSS}},\qquad R^2=1-\frac{\mathrm{RSS}}{\mathrm{TSS}}$$

Uncertainty in the coefficients

$$\hat\sigma^2=\frac{\mathrm{RSS}}{n-(p+1)},\qquad \operatorname{Cov}(\hat\beta)=\hat\sigma^2(X^\top X)^{-1},\qquad t_j=\frac{\hat\beta_j}{\mathrm{SE}(\hat\beta_j)}$$

A large \(|t|\) (roughly above 2) is evidence that the coefficient is not zero. Try the Advertising dataset to get a real-data regression table, then drag a point far away and watch the standard errors react.

3Gradient descent on the loss surface

The closed form is not the only route. Gradient descent starts somewhere on the bowl \(J(\beta_0,\beta_1)=\tfrac{1}{2n}\mathrm{RSS}\) and steps downhill: \(\beta\leftarrow\beta-\eta\,\nabla J=\beta+\tfrac{\eta}{n}X^\top(y-X\beta)\). Click the contour plot to choose a starting point.

Contours are log-spaced levels of \(J\). The star is the closed-form \(\hat\beta\).

4Polynomial features and the bias–variance trade-off

A degree-\(d\) polynomial is still linear regression, because the model is linear in \(\beta\): \(\hat y=\beta_0+\beta_1x+\beta_2x^2+\dots+\beta_dx^d\). Raising \(d\) lowers training error every time, but test error is U-shaped.

training MSEtest MSE (fresh data from the same source)dashed line = your current degree
$$\mathbb E\big[(y-\hat f(x))^2\big]=\underbrace{\big(f(x)-\mathbb E\hat f(x)\big)^2}_{\text{bias}^2}+\underbrace{\operatorname{Var}\hat f(x)}_{\text{variance}}+\underbrace{\sigma^2}_{\text{noise}}$$
  • Low degree: the model is too rigid. High bias, low variance, so training and test error are both high (underfitting).
  • High degree: the curve chases noise. Low bias, high variance, so training error keeps falling while test error climbs (overfitting).
  • Regularisation (section 5) is the other dial: keep a high degree but shrink the coefficients.

5Ridge and lasso: shrinkage versus sparsity

Both add a penalty on the size of \(\beta\) (features standardised, intercept not penalised). The shape of the penalty changes what the solution looks like.

$$\text{Ridge: }\min_\beta\ \tfrac1n\lVert y-X\beta\rVert_2^2+\lambda\lVert\beta\rVert_2^2\ \Rightarrow\ \hat\beta=(X^\top X+n\lambda I)^{-1}X^\top y$$
$$\text{Lasso: }\min_\beta\ \tfrac1{2n}\lVert y-X\beta\rVert_2^2+\lambda\lVert\beta\rVert_1\ \Rightarrow\ \beta_j\leftarrow S_\lambda\!\Big(\tfrac1n x_j^\top r_{(j)}\Big),\ S_\lambda(z)=\operatorname{sign}(z)(|z|-\lambda)_+$$

Lasso has no closed form; it is solved by coordinate descent with the soft-thresholding operator \(S_\lambda\), which sets small coefficients to exactly zero. Ridge only shrinks them towards zero.

Why the diamond gives zeros

Equivalently, minimise RSS subject to \(\lVert\beta\rVert\le t\). The RSS contours are ellipses around the OLS solution. They usually first touch the L2 circle at a generic point, but they first touch the L1 diamond at a corner, where one coordinate is zero. Drag the OLS point (the star) on the right-hand plot to see it.

Coefficient paths on your current data (degree )

Ridge: every coefficient shrinks smoothly and reaches zero only as \(\lambda\to\infty\).

Lasso: coefficients hit zero one by one, which is automatic feature selection.

Paths need several features, so they use degree \(\max(d,6)\). The dashed line marks your current \(\lambda\).

6The same thing in Python

import numpy as np
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.pipeline import make_pipeline

# closed form
X = np.column_stack([np.ones(len(x)), x])
beta = np.linalg.solve(X.T @ X, X.T @ y)          # (X^T X)^{-1} X^T y, without forming the inverse
e = y - X @ beta; RSS = e @ e; R2 = 1 - RSS / np.sum((y - y.mean())**2)
se = np.sqrt(np.diag(RSS / (len(y) - 2) * np.linalg.inv(X.T @ X)))

# polynomial + penalty, as on this page
model = make_pipeline(PolynomialFeatures(degree=6, include_bias=False), StandardScaler(),
                      Lasso(alpha=0.1))     # or Ridge(alpha=...), LinearRegression()
model.fit(x.reshape(-1, 1), y)

Note that scikit-learn's Ridge(alpha) uses \(\lVert y-X\beta\rVert^2+\alpha\lVert\beta\rVert^2\) (no \(1/n\)), so its \(\alpha\) equals \(n\lambda\) here. Lasso(alpha) uses the same \(\tfrac1{2n}\) scaling as this page.
