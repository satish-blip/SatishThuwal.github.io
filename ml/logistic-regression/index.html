What is logistic regression, in plain words?

The idea

Despite the name, logistic regression is a classifier. It computes a weighted score from the inputs, exactly like linear regression, then squashes that score through the sigmoid curve to get a probability between 0 and 1: "73% chance this email is spam".

The weights are chosen so the predicted probabilities match the true labels as well as possible, measured by the log-loss. Where the probability crosses 0.5 is the decision boundary, a straight line unless you add polynomial features.

How it works

  1. Score: \(z = w^\top x + b\).
  2. Probability: \(p = \sigma(z) = 1/(1+e^{-z})\).
  3. Loss: penalise confident wrong answers heavily (cross-entropy).
  4. Minimise it with gradient descent or Newton’s method; add an L2 or L1 penalty to keep weights in check.
  5. Predict class 1 when \(p\) is above a threshold.

An everyday picture

A bank deciding whether to approve a loan: income and debt go in, a probability of repayment comes out, and the bank chooses how cautious to be by moving the threshold.

Good at
  • Gives calibrated probabilities, not just labels
  • Weights are interpretable as changes in log-odds
  • Convex: always finds the best weights
Watch out for
  • Linear boundary unless you engineer features
  • Weights blow up on perfectly separable data without regularisation

Learned weights

Features are polynomial terms \(x_1^ax_2^b\), standardised before fitting. For degree 1 the boundary is the line \(w_0+w_1\tilde x_1+w_2\tilde x_2=0\).

2The sigmoid and the log-loss

loss if the true label is 1: \(-\log p\)loss if the label is 0: \(-\log(1-p)\)

Confident and wrong is punished without limit: at \(p=0.01\) for a true 1, the loss is \(4.6\). That is why the optimiser fights hard for every misclassified point, and why perfectly separable data sends \(\lVert w\rVert\to\infty\) without a penalty.

3The maths

Model: linear log-odds

$$P(y=1\mid x)=\sigma(w^\top x)=\frac{1}{1+e^{-w^\top x}}\qquad\Longleftrightarrow\qquad \log\frac{P(y=1\mid x)}{P(y=0\mid x)}=w^\top x$$

The boundary \(P=0.5\) is where \(w^\top x=0\): a hyperplane in feature space. With polynomial features \(\phi(x)\) it becomes a curve in the original space, but the model is still linear in \(w\).

Maximum likelihood = minimum cross-entropy

$$L(w)=-\frac1n\sum_{i=1}^n\Big[y_i\log p_i+(1-y_i)\log(1-p_i)\Big]+\frac\lambda2\lVert w\rVert^2,\qquad p_i=\sigma(w^\top x_i)$$

Using \(\sigma'(z)=\sigma(z)(1-\sigma(z))\), the gradient collapses to a remarkably simple form, the same shape as least squares:

$$\nabla L(w)=\frac1n X^\top(p-y)+\lambda w$$

Gradient descent: \(w\leftarrow w-\eta\,\nabla L(w)\). There is no closed form, unlike linear regression, because \(p\) depends non-linearly on \(w\).

Convexity and Newton's method

$$\nabla^2L(w)=\frac1nX^\top S X+\lambda I,\qquad S=\operatorname{diag}\big(p_i(1-p_i)\big)\succeq0$$

The Hessian is positive semi-definite, so \(L\) is convex: any local minimum is global, and gradient descent with a small enough step will find it. Newton's method uses curvature too, \(w\leftarrow w-(\nabla^2L)^{-1}\nabla L\). This is the same as iteratively reweighted least squares (IRLS) and usually converges in under 10 steps. Press Solve (Newton) and compare with gradient descent.

Separable data

If a hyperplane separates the classes perfectly, scaling \(w\) up always lowers the loss, so with \(\lambda=0\) the weights grow forever and probabilities become 0 or 1. Choose Linear blobs, set λ to its minimum and run GD: watch \(\lVert w\rVert\) climb. The L2 penalty fixes this.

L1 instead of L2. Replacing \(\tfrac\lambda2\lVert w\rVert^2\) by \(\lambda\lVert w\rVert_1\) makes the loss non-differentiable at 0, so Newton no longer applies. The page then uses proximal gradient descent: a gradient step on the cross-entropy, followed by soft-thresholding \(w_j\leftarrow\operatorname{sign}(w_j)\max(0,|w_j|-\eta\lambda)\). Weights that do not earn their keep land exactly on 0. Pick degree 6, switch to L1 and raise λ: watch the number of non-zero weights fall. More on the L1 and L2 regularisation page.

Compared with LDA

LDA also gives linear log-odds, but it gets \(w\) by modelling each class as a Gaussian. Logistic regression fits \(P(y\mid x)\) directly (discriminative) and makes no assumption about how \(x\) is distributed, so it is more robust when the Gaussian assumption is wrong.

5The same thing in Python

from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.metrics import confusion_matrix, roc_auc_score

clf = make_pipeline(PolynomialFeatures(3, include_bias=False), StandardScaler(),
                    LogisticRegression(C=1 / (n * lam)))   # sklearn's C is the inverse penalty
clf.fit(X, y)
p = clf.predict_proba(X)[:, 1]
confusion_matrix(y, p >= 0.5), roc_auc_score(y, p)
