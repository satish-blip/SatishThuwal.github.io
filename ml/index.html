Traditional ML · Interactive lab

Machine learning, you can touch

A visual repository of the classic algorithms from my IIT Bombay course. Every page pairs live visuals with the maths, and every model is written from scratch in plain JavaScript and trained in your browser as you move the sliders. Nothing is pre-computed.

Regression

Linear Regression

Drag points and watch least squares refit. Residual squares, the normal equations with your numbers, R² and standard errors (TA Tutorial 3), gradient descent on the loss bowl, bias–variance, ridge vs lasso.

Classification

Logistic Regression

Train it step by step with gradient descent or Newton. Probability contours, the sigmoid and log-loss, polynomial features, and a movable threshold with confusion matrix and ROC curve.

Generative

LDA & GDA

Fit a Gaussian to each class and classify with Bayes. LDA vs QDA vs naive Bayes, drag the class means, change priors, find Fisher’s projection and sample fake data.
